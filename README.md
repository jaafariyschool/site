# عن مدرستنا


الجعفرية الثانوية المهنية للبنات إحدى مدارس مديرية التربية والتعليم للواء المزار الجنوبي. درّست هذه المدرسة العديد من الأجيال على مدى سنوات طويلة، وتخرّجت منها طالبات حملن علمها وقيمها إلى ميادين كثيرة.

وفي السنوات الأربع الأخيرة دخل المدرسةَ نظام التعليم المهني BTEC، فأصبحت طالباتنا يجمعن بين المعرفة والتطبيق العملي في تخصصات تواكب سوق العمل.
